Complete reference guide for interacting with the TaskFlow task tracking backend engine.

Base URL & Authentication

All API requests should be made to the local simulation base URL:

http://localhost:8080/api

No authentication header is required for this local environment instance.

Endpoints

GET /tasks
List all tasks

Returns a JSON array of all task objects matching optional query parameters.

Query Parameters

statusstringFilter by status (todo, in-progress, completed)
prioritystringFilter by priority (low, medium, high)
POST /tasks
Create task

Creates a new task in the database and returns the created object with generated ID.

JSON Body Schema

{
  "title": "String (Required)",
  "description": "String (Optional)",
  "priority": "low | medium | high (Default: medium)",
  "status": "todo | in-progress | completed (Default: todo)",
  "tags": ["Array", "of", "strings"]
}
PUT /tasks/:id
Update task

Updates any field of an existing task by ID.

DELETE /tasks/:id
Delete task

Deletes the task specified by ID from the datastore.
